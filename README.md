# Sthander Jurídico

Sistema de gestão para pequenos escritórios de advocacia, com cadastro de clientes,
atendimentos, documentos, processos, peças, agenda, financeiro e monitoramento processual.

Endereço planejado: `juridico.sthanderinfo.com.br`

## Princípios do projeto

- Desenvolvimento e validação em etapas pequenas.
- Dados e documentos privados por padrão.
- Consulta automática somente por fontes oficiais e autorizadas.
- Prazos e atos jurídicos sempre sujeitos à confirmação humana.
- Certificados digitais e respectivas senhas nunca armazenados no servidor.
- Cada etapa deve ser testada e aprovada antes da seguinte.

## Primeira entrega

A Etapa 1 contempla a fundação do sistema: organização de escritórios,
usuários, perfis de acesso, autenticação, auditoria e painel inicial.
